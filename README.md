# entreno-app

La interfaz de una app personal de entrenamiento. **Aquí no hay ni un dato personal**:
solo el código de la página. Los datos viven en un repositorio privado aparte y la app
los lee en tiempo de ejecución con un token que está únicamente en el móvil.

- Se publica sola con GitHub Pages en cada `push`.
- PWA: instalada en la pantalla de inicio funciona sin cobertura.
- Sin framework, sin dependencias, sin paso de compilación.

## Por qué este repo es público

GitHub Pages sobre un repositorio privado exige plan de pago. Separar el código
(público, sin datos) de los datos (privados) sale gratis y además reduce lo expuesto:
quien encuentre este repo ve una interfaz vacía sin nada que leer.
